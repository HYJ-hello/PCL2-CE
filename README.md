## 📖 项目介绍

**PCL Community Edition (PCL2-CE)** 是基于官方 **Plain Craft Launcher 2** 进行二次开发的社区版本，致力于为 Minecraft 玩家提供更强大的功能和更好的使用体验。

### 🌟 为什么选择 PCL CE？



* **🔧 功能增强**：包含主线暂未制作的实用功能和改进

* **🌍 社区驱动**：由活跃的开发者社区维护和更新

* **🎯 专注玩家**：专为中国玩家优化，支持国内高速下载源

* **💻 开源免费**：完全开源，永久免费使用

* **🔒 安全可靠**：开源透明，安全无忧

### 🚀 社区版特色功能

相比官方版本，PCL CE 新增了以下特色功能：

#### 🔗 联机功能



* **无需正版验证**：离线用户也可以正常使用

* **简单操作**：一键创建房间，好友通过邀请码即可加入

* **跨网络支持**：支持不同网络环境下的联机游戏

#### 📦 资源管理增强



* **模组收藏夹**：收藏喜欢的模组，方便快速浏览和管理

* **自动翻译**：支持模组简介自动翻译功能

* **资源分享**：收藏夹支持导出导入，方便与好友分享

#### 🎨 个性化体验



* **深色模式**：支持深色 / 浅色主题切换，保护视力

* **字体自定义**：可调节启动器字体（目前支持英文）

* **界面优化**：更直观的实力信息显示

#### 🔧 技术增强



* **多加载器支持**：新增 Quilt 模组加载器支持

* **智能修复**：自动修复丢失的 OptiFine 和 Forge 主文件

* **Java 管理**：自动检测和管理 Java 版本


* 如果提示缺少 .NET 环境，请下载并安装对应版本

* 首次运行会自动检测 Java 环境

## 🎮 使用教程

### 🔑 首次使用

#### 1. 启动启动器



```
双击 Plain Craft Launcher 2.exe 启动程序

首次运行可能需要等待几秒钟加载
```

#### 2. 登录方式选择



```
\- 正版登录：已有 Minecraft 正版账号

\- 离线登录：无需购买，输入任意用户名即可
```

#### 3. 下载游戏版本



```
1\. 点击 "下载" 标签页

2\. 选择想要的 Minecraft 版本

3\. 点击 "开始下载"

4\. 等待下载完成（建议选择国内镜像源）
```

### 📦 模组管理

#### 安装模组



```
方法一：拖拽安装

1\. 下载 .jar 格式的模组文件

2\. 直接拖拽到启动器窗口

3\. 选择要安装的游戏版本

4\. 点击确定完成安装

方法二：手动安装

1\. 点击 "模组" 标签页

2\. 点击 "添加模组"

3\. 选择下载好的模组文件

4\. 完成安装
```

#### 模组收藏功能



```
1\. 在模组详情页面点击 "收藏" 按钮

2\. 收藏的模组会显示在 "收藏夹" 中

3\. 支持对收藏的资源添加备注

4\. 可通过 "分享" 功能与好友分享收藏夹
```

### 🌐 联机功能使用

#### 创建房间



```
1\. 启动 Minecraft 游戏

2\. 创建或进入单人世界

3\. 按 ESC 键，选择 "对局域网开放"

4\. 点击 "创建局域网世界"

5\. 记住显示的端口号

6\. 在启动器点击 "联机" 标签页

7\. 点击 "刷新" 找到你的世界

8\. 点击 "创建" 生成邀请码

9\. 将邀请码分享给好友
```

#### 加入房间



```
1\. 在启动器点击 "联机" 标签页

2\. 点击 "加入大厅"

3\. 粘贴好友分享的邀请码

4\. 点击 "确定"

5\. 复制显示的服务器地址

6\. 在游戏中点击 "多人游戏"

7\. 点击 "添加服务器"

8\. 粘贴服务器地址并保存

9\. 双击服务器进入游戏
```

### 🎨 个性化设置

#### 主题切换



```
1\. 点击右上角设置按钮

2\. 选择 "个性化"

3\. 在 "主题" 选项中选择：

&#x20;  \- 浅色模式

&#x20;  \- 深色模式 &#x20;

&#x20;  \- 跟随系统

4\. 点击 "应用" 保存设置
```

#### JVM 参数优化



```
1\. 点击 "设置" 标签页

2\. 选择 "Java"

3\. 在 "JVM 参数" 中设置：

&#x20;  \- 建议内存分配：-Xmx4G -Xms2G

&#x20;  \- 优化参数：-XX:+UseG1GC

4\. 点击 "保存" 应用设置
```

## ❓ 常见问题 FAQ

### 🔧 启动问题

**Q: 启动器闪退怎么办？**

A:



1. 检查 .NET 环境是否正确安装

2. 确保使用最新版本的启动器

3. 尝试以管理员身份运行

4. 检查系统是否满足最低要求

**Q: 提示 "无法加载点云数据"？**

A:



1. 确认文件路径正确且无中文

2. 检查 Minecraft 文件完整性

3. 尝试重新下载游戏版本

4. 清理启动器缓存

### 📥 下载问题

**Q: 下载速度很慢？**

A:



1. 进入 "设置 - 下载源"

2. 选择 "国内镜像源"

3. 确保网络连接稳定

4. 尝试使用网络加速工具

**Q: 下载中断或失败？**

A:



1. 检查网络连接

2. 清理临时文件

3. 更换下载源

4. 重启启动器重试

### 🎮 游戏问题

**Q: 游戏卡顿严重？**

A:



1. 增加内存分配（建议 4GB 以上）

2. 安装 OptiFine 优化画质

3. 关闭不必要的后台程序

4. 降低游戏画质设置

**Q: 模组冲突导致崩溃？**

A:



1. 禁用全部模组

2. 逐个启用模组测试

3. 检查模组版本兼容性

4. 查看崩溃日志定位问题模组

### 🌐 联机问题

**Q: 无法创建或加入房间？**

A:



1. 检查网络连接

2. 确保双方使用相同版本启动器

3. 尝试重启启动器

4. 检查防火墙设置

**Q: 联机时延迟很高？**

A:



1. 确保网络稳定

2. 尝试使用网络加速工具

3. 选择延迟较低的服务器

4. 关闭其他占用网络的程序
